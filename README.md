# Red de Clínicas Adventistas — Nueva Web

Proyecto de rediseño de la web (https://clinicasadventistas.org) orientada a **conversión**:
citas presenciales, consultas online y captación de leads.

## Estructura del repositorio

| Carpeta | Contenido |
|---------|-----------|
| [`docs/`](docs/) | Estrategia, rediseño, arquitectura, plan de acción y propuesta de diseño. **Empieza por [`docs/README.md`](docs/README.md).** |
| [`propuestas-diseno/`](propuestas-diseno/) | Mockups visuales para autorizar el diseño. Abre [`inicio.html`](propuestas-diseno/inicio.html) en el navegador. |
| [`contenido-original/`](contenido-original/) | Aquí subes el ZIP del contenido actual para analizar y migrar. |

## Decisiones de arranque

- **Conversión:** las 3 rutas por igual (cita presencial · consulta online · lead).
- **Plataforma (recomendada):** Astro + Tailwind CSS sobre DigitalOcean.
- **Diseño:** premium / corporativo.

## Próximos pasos

1. Subir el ZIP de contenido a `contenido-original/`.
2. Revisar y **autorizar** la propuesta de diseño (`docs/06-propuesta-de-diseno.md` + mockup).
3. Iniciar desarrollo en Astro y migración de contenido.
