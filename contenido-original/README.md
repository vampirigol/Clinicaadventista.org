# Contenido original del sitio

Coloca aquí el contenido exportado del sitio actual (https://clinicasadventistas.org)
para que pueda analizarlo y migrarlo.

## Cómo subir el ZIP (recomendado)

1. Añade tu archivo (por ejemplo `export-clinicas.zip`) **dentro de esta carpeta**.
2. Haz **commit** y **push** a la rama `claude/nifty-mendel-bW9b5`.
3. **Avísame en el chat** y haré `git pull` para extraerlo y analizarlo.

> ¿Prefieres no usar git? También puedes **adjuntar el ZIP directamente en el chat**
> de Claude Code si tu aplicación lo permite y el archivo no es muy pesado.
> (Evita enlaces a Drive/Dropbox privados: no puedo abrir URLs que requieran iniciar sesión.)
